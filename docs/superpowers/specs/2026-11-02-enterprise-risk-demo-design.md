# 企业合规风险巡检演示设计

## 产品名称

衡源风控（Hengyuan Risk Ops）。页面标题为「衡源 · 企业风险巡检」，副标识为 `ENTERPRISE RISK OPS`，AI 助手名为「衡源 Agent」。

## 目标

构建一个适合比赛现场演示的企业合规风险巡检 Demo，围绕“企业台账 → 批量定时巡检 → gov 权威检索 → 交叉核验 → 风险分级 → 告警处置 → 周报归档 → AI 追问”形成完整闭环。

## 用户硬性要求

1. 批量企业定时巡检。
2. gov 权威检索。
3. 分级告警。
4. 自动周报。
5. 双入口：Web 风控驾驶舱 + AI 风控助手。

## 设计边界

这是可现场操作的前端 Demo。默认使用稳定的演示数据和模拟运行过程，支持切换为“真实接口占位”状态；不在前端保存真实密钥，不把文档中的示例企业名或密钥当作生产配置。真实 SearchPro/MCP 接入时，保持现有数据结构和页面行为不变。

## 演示主线

1. 在总览页看到 35 家企业、最近周期状态和风险概览。
2. 点击“运行本周期巡检”，进入任务详情。
3. 观察台账、gov 检索、交叉核验、风险分级、告警和周报六个步骤依次完成。
4. 打开高风险事件，查看官方原文链接和两条权威信源的核验证据。
5. 在告警中心确认并指派高风险事件。
6. 在周报中心打开自动生成的周报。
7. 在 AI 助手中追问单个企业，看到 Agent 拆解查询、返回结论并支持加入告警。

## 页面与职责

### 总览驾驶舱

首屏展示监控企业数、本周期完成率、风险总数和待处理高风险。主区包含风险趋势、风险等级分布、最近高风险事件和六步闭环状态条。右上角提供“运行本周期巡检”主操作。

### 企业台账

展示企业名称、统一社会信用代码、行业、监控状态、最近巡检、当前等级和告警状态。支持导入企业、勾选企业后立即巡检、设置频率和风险类型。

### 巡检任务

展示任务周期、企业数、完成率、耗时和风险数。任务详情显示单家企业的四类查询进度、Agent 执行日志和失败重试入口。

### 风险事件

使用可筛选表格展示企业、风险类型、等级、发现时间、证据强度和处理状态。点击事件打开证据抽屉，包含事件摘要、gov 原文、来源域名、交叉核验来源和判级原因。

### 告警中心

按照待处理、已确认、已忽略、已关闭管理告警。高风险支持确认、指派负责人、添加备注和关闭；展示企业微信、邮件和站内通知的发送记录。

### 周报中心

展示自动生成的周报列表和摘要指标，支持预览、复制和下载 HTML/Markdown。报告内的每条风险保留 gov 官方原文链接。

### AI 风控助手

支持输入企业名称或自然语言问题。Agent 自动拆分为处罚、经营异常、招投标和资质四组检索，流式展示检索进度，返回结构化结论、等级、依据与官方链接，并支持追问和加入告警。

### 系统设置

仅保留演示所需配置：巡检频率、Freshness、风险规则、告警渠道、gov 信源状态、Demo/真实接口模式。

## 数据流

```text
企业台账
  -> 任务调度器
  -> Query Agent 拆解四类查询
  -> SearchPro gov 检索（Freshness + Deeplinks）
  -> 结果清洗与去重
  -> 多源交叉核验
  -> 风险分级
  -> 风险事件库
  -> 告警路由 + 周报聚合
  -> Web 驾驶舱 / AI 助手 / MCP 调用
```

## 核心状态机

巡检任务状态：`待运行` → `运行中` → `已完成` / `部分失败`。

风险事件状态：`新发现` → `待确认` → `已确认` → `处理中` → `已关闭`，也可从 `待确认` 转为 `已忽略`。

告警路由：高风险立即推送企业微信 + 邮件 + 站内；中风险进入站内待办并汇总至周报；低风险只进入周报。

## 视觉与交互原则

- 深色侧栏承载导航和产品识别，浅色主区承载数据阅读。
- 风险颜色只用于等级、状态和趋势，不覆盖整块页面。
- 表格承担高密度信息，抽屉承担证据详情，避免层层嵌套卡片。
- 每个异步动作都显示状态、耗时、结果数和失败重试入口。
- 所有页面保留当前巡检周期和数据源状态，确保演示时用户不会迷失。
- 主按钮使用明确动词：运行巡检、查看证据、确认告警、生成周报。

## 非功能要求

- 本地启动即可演示，首次打开不依赖网络。
- 关键操作有即时反馈和可重复触发行为。
- 移动窄屏至少保持导航、指标和表格可读。
- 页面文案使用中文，必要的 API 参数以小标签形式展示。
